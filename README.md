# ProjectoFinalAndroid
En este repositorio vamos a agregar nuestros avances del proyecto junto con el finalizado. 

## Equipo de desarrollo

El proyecto BORA es desarrollado por un equipo de cinco integrantes.
Las responsabilidades principales se distribuyen de la siguiente manera:

### Desarrollo de aplicación móvil
**Jordan Rosas y Cristóbal Vargas**

Responsables principalmente del desarrollo de la aplicación Android,
implementación de pantallas, navegación y funcionalidades móviles.

### Backend y servicios
**Camila Solís**

Responsable principalmente de la base de datos, autenticación,
servicios y gestión de la información utilizada por las diferentes
plataformas de BORA.

### UX/UI, desarrollo web y documentación
**Javiera Almonacid y David Soto**

Responsables principalmente del diseño de interfaces y experiencia
de usuario, identidad visual de BORA, documentación del proyecto,
desarrollo de la vitrina web y panel de administración web.

## Trabajo colaborativo

Aunque existen áreas principales de responsabilidad, el desarrollo
de BORA se realizará de manera colaborativa. Los integrantes podrán
participar y apoyar otras áreas del proyecto cuando sea necesario,
manteniendo coordinación entre aplicación móvil, web, backend y diseño.
